# 🏦 Banking System Simulation (Python OOP)

Это проект на языке Python, демонстрирующий принципы объектно-ориентированного программирования (ООП) на примере банковской системы. В системе реализованы различные типы счетов, управление клиентами, многоуровневая обработка ошибок и логика безопасности.

## 🚀 Основные возможности

* **Иерархия счетов**. Использование абстрактных классов и наследования для создания различных финансовых инструментов.
* Проверка возрастных ограничений при регистрации (18+).
* Блокировка клиента после 3-х неудачных попыток входа.
* Заморозка и закрытие счетов.
* **Умные уведомления**. Система имитирует отправку СМС, учитывая время суток (запрет на беспокойство ночью).
* **Инвестиционный модуль**. Возможность покупки активов и прогнозирования годовой доходности портфеля.
* **Кастомные исключения**. Обработка специфических банковских ошибок (недостаточно средств, неверная валюта и т.д.).

---

## 📁 Структура проекта

### 🏗️ Ядро системы

* **`AbstractAccount.py`**. Абстрактный базовый класс, определяющий обязательный интерфейс для всех счетов.
* **`BankAccount.py`**. Базовая реализация счета (депозит, снятие, проверка статуса). Поддерживает мультивалютность (`RUB`, `USD`, `EUR` и др.).
* **`Bank.py`**. Центральный контроллер системы. Управляет реестром клиентов, связывает счета и проводит аудит крупных транзакций.
* **`Client.py`**. Класс пользователя. Отвечает за хранение личных данных, аутентификацию и список личных счетов.

### 💳 Типы счетов

* **`SavingAccount.py` (Сберегательный)**. Требует наличия неснижаемого остатка. Позволяет рассчитывать ежемесячную прибыль по процентной ставке.
* **`PremiumAccount.py` (Премиальный)**. Позволяет уходить в минус (овердрафт), но берет комиссию за каждую операцию снятия.
* **`InvestmentAccount.py` (Инвестиционный)**. Позволяет покупать акции и облигации, отслеживать состав портфеля и прогнозировать рост капитала.

### ⚠️ Обработка ошибок

* **`errors.py`**. Набор пользовательских исключений:
* `InsufficientFundsError` — нехватка денег.
* `AccountFrozenError` — операции со счетом заблокированы.
* `AuthenticationError` — ошибка входа или блокировка профиля.
* `AgeRestrictionError` — отказ в регистрации несовершеннолетним.

## 🛠️ Технологический стек

* **Язык**: Python
* **Абстракция**: Использование модуля `abc`.
* **Наследование**: Расширение базового функционала `BankAccount` в специализированных классах.
* **Инкапсуляция**: Защищенные атрибуты (например, `_balance`) и методы валидации.
* **Полиморфизм**: Переопределение методов `withdraw` и `get_account_info` для разных типов логики.

## 🚦 Как запустить

1. Убедитесь, что у вас установлен Python 3.
2. Скачайте все файлы в одну директорию.
3. Запустите главный файл для проведения тестов:

```bash
python main.py

```

## 📝 Пример использования (main.py)

В файле `main.py` реализован сценарий, который:

1. Создает сберегательный счет и проверяет лимит остатка.
2. Имитирует покупку акций Apple через инвестиционный счет.
3. Пытается зарегистрировать несовершеннолетнего пользователя (вызывает исключение).
4. Демонстрирует блокировку клиента после трех неверных паролей.
5. Проверяет работу системы при заморозке счета банком.
